# Architecture Decision Records

This directory records significant Cyber Range architecture decisions.

## ADR Principles

- Record decisions after they are established or approved.
- State the context and problem.
- Record the selected decision.
- Record alternatives and trade-offs where known.
- Do not invent historical approval or implementation evidence.
- An ADR does not itself change infrastructure.
- Current implementation and future target state remain separate.
