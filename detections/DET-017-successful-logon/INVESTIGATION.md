# DET-017 — Investigation Evidence

## Evidence Chain

### 1. Controlled Authentication

Command executed on DC-01:

```powershell
runas /user:CORP\admin cmd.exe
```

The controlled action produced a Windows Security Event 4624.

### 2. Windows Event 4624

Observed event:

- Time: `09/28/2026 09:02:03`
- Event ID: `4624`
- Account: `CORP\\admin`
- Account SID: `S-1-5-21-2519611076-441997742-1464114610-1000`
- Logon Type: `2`
- Elevated Token: `Yes`
- Logon ID: `0x2C5499`
- Workstation: `DC-01`
- Source Network Address: `::1`
- Process: `C:\Windows\System32\svchost.exe`
- Logon Process: `seclogo`
- Authentication Package: `Negotiate`

A linked session was also observed with Logon ID `0x2C54AA`. The evidence set therefore contains both linked successful-logon records generated by the controlled runas action.

### 3. Wazuh Ingestion

The corresponding event was present in:

```
wazuh-alerts-4.x-2026.09.28
```

Observed Wazuh record:

- Timestamp: `2026-09-28T03:33:20.070Z`
- Rule ID: `60118`
- Rule description: `Windows Workstation Logon Success`
- Event ID: `4624`
- Target username: `admin`
- Target domain: `CORP`
- Logon Type: `2`
- Target Logon ID: `0x2c5499`
- IP address: `::1`

### 4. SIEM Investigation Pivot

Querying Wazuh for:

```
agent.name = DC-01
data.win.eventdata.targetLogonId = 0x2c5499
```

returned:

```
hits.total = 1
```

The single returned record was the same 4624 successful interactive logon for `CORP\\admin`.

### 5. Investigation Interpretation

The evidence supports the following chain:

```
Controlled runas
    ↓
Windows Security 4624
    ↓
Logon ID 0x2c5499
    ↓
Wazuh rule 60118
    ↓
Wazuh Logon ID pivot
    ↓
1 matching event
```

The source address `::1` identifies the activity as local to DC-01. No claim of remote authentication should be made from this test.

The successful authentication demonstrates telemetry and investigation capability, but does not independently establish malicious use of valid credentials.

## Investigation Result

**PASS**

The Logon ID from Windows Event 4624 was successfully used as a SIEM investigation pivot and returned the corresponding Wazuh event.
